## Goal
Create API endpoints to manage students.

## Tasks
- [ ] Implement student service and controller methods.
- [ ] Register routes under `/api/v1/students`.
- [ ] Support create, list, get by ID, update, and delete.
- [ ] Validate student fields and `classId`.
- [ ] Verify the referenced class exists.
- [ ] Keep `studentCode` unique and handle duplicate-key errors.
- [ ] Decide whether `studentCode` is generated by the backend or supplied by an authorized client.

## Acceptance criteria
- [ ] Student CRUD endpoints work.
- [ ] Invalid/nonexistent class references are rejected.
- [ ] Duplicate student codes return `409 Conflict`.
