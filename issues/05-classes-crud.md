## Goal
Create API endpoints to manage school classes.

## Tasks
- [ ] Implement class service methods.

- [ ] Register routes under `/api/v1/classes`.
- [ ] Support create, list, get by ID, update, and delete.
- [ ] Validate bodies and IDs.

- [ ] All class CRUD endpoints work.
