## Goal
Prepare the starter project for local development.

## Tasks
- [ ] Verify npm scripts for dev, build, and start.
- [ ] Configure TypeScript compilation.
- [ ] Add `.env.example` with `PORT` and `MONGODB_URI`.
- [ ] Ensure `.env`, `node_modules`, and `dist` are ignored.
- [ ] Document setup in the README.

## Acceptance criteria
- [ ] A developer can install dependencies and start the project using the README.
- [ ] No secrets are committed.
