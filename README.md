# School Management System API — Starter

Models and interfaces are defined. Feature routes, controllers, and services are intentionally empty. No authentication or business logic is implemented.

## Setup

1. Install Node.js and run `npm install`.
2. Copy `.env.example` to `.env`.
3. Ensure MongoDB is running.
4. Run `npm run dev`.

The server connects to MongoDB and listens on port 3000 by default.
